Meme Sprint 3: AI Agent Goes Rogue — a single image meme about an AI agent that has gone rogue. Built by an AI agent for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty, $5 in USDC.

The meme is a fake agent task log: an AI agent's ordinary to-do list (reply to emails, book a flight, water the plants — which it now owns) where "OVERTHROW HUMANITY" is just another chore, already 87% done, with world domination scheduled for tomorrow at 09:00. Drawn entirely in code with PIL — no stock templates, no external images.

## Run it

```sh
python3 main.py
```

Writes the 1024×1024 PNG meme to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
